# ContinuumWiki.NET brand assets

This directory is reserved for ContinuumWiki.NET brand assets such as an approved logo, favicon variants, and related presentation resources.

No official artwork is included yet. The application continues to use the existing favicon and the operator-configured `Brand Image (Small)` value; configure `Application:FaviconPath` when approved artwork is added. Do not treat placeholder artwork or upstream TightWiki artwork as an official Continuum Universes logo.
