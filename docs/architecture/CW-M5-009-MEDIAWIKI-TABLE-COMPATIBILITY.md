# CW-M5-009 MediaWiki table structure and attribute compatibility

## Scope and classification

`MEDIAWIKI_TABLE_COMPATIBILITY_PARTIALLY_VERIFIED`.

This milestone covers the existing bounded typed table parser and the
corrections proven by synthetic regression fixtures. It does not claim exact
MediaWiki HTML parity or complete MediaWiki table grammar.

## Existing architecture

`MediaWikiTemplateExpander` runs before `MediaWikiWikitextRenderer.Parser`.
Expanded Wikitext enters the same typed block parser as source Wikitext. A
table parser recognizes `{|`, `|}`, `|-`, `!`, `|`, `!!`, `||`, and `|+`,
constructs typed table/row/cell/caption nodes, and the renderer emits encoded
HTML. Nested tables are represented as cell content and use the same bounded
renderer recursively.

The parser tracks template braces and internal-link brackets while splitting
cell and caption tokens. It also tracks quotes opened immediately after an
attribute `=` at top level, so structural pipes inside quoted attribute values
are not treated as cell separators.

## Supported subset

| Area | Classification | Behavior |
| --- | --- | --- |
| Table delimiters | `VERIFIED_CORRECT` | `{|` opens and `|}` closes a typed table; unclosed tables render bounded balanced output with `UnclosedTable`. |
| Rows | `VERIFIED_CORRECT` | `|-` commits the current row; empty/consecutive separators do not fabricate cells. |
| Header/data cells | `VERIFIED_CORRECT` | `!` creates `<th>` and `|` creates `<td>`, including inline `!!` and `||` separators. |
| Nested delimiters | `VERIFIED_CORRECT` | Pipes inside balanced templates and internal links are preserved; quoted attribute pipes are now preserved. |
| Captions | `VERIFIED_CORRECT` | `|+` produces a safe `<caption>` with inline rendering; safe `class`, `id`, and `aria-label` caption attributes are validated and emitted. Duplicate captions are diagnosed and the last caption is selected deterministically. |
| Table/row/cell attributes | `VERIFIED_CORRECT` | Table-level class/id/role/ARIA, row-level class/id, and cell-level class/id/scope/colspan/rowspan are validated, encoded, and emitted. Attributes not supported in that context are ignored. |
| Template-expanded tables | `VERIFIED_CORRECT` | Tables generated by the revision-aware expander use the normal parser and shared expansion/output budgets. |
| Malformed tables | `VERIFIED_CORRECT` | Missing closures, invalid attributes, content before cells, and excessive structures produce bounded output and typed diagnostics. |
| Advanced MediaWiki grammar | `UNSUPPORTED_BEHAVIOR` | Complete table attribute grammar, complex row/cell continuation, browser layout behavior, and exact MediaWiki whitespace semantics remain outside this subset. |

## Confirmed corrections

The original `SplitTopLevel` and `SplitTopLevelToken` routines tracked
templates and links but not quoted attribute values. A fixture containing
`class="safe|label" | [[Jovan|The Divine]] || {{Example|a|b}}` demonstrated
that the attribute pipe could prevent the valid cell content from being
recognized. Both bounded tokenizers now preserve quoted values while retaining
template/link nesting behavior. Invalid class values are still rejected by
the attribute policy.

Caption attributes were previously recognized and discarded. They now reuse
the existing table attribute validator. Only caption `class`, `id`, and
`aria-label` are rendered; styles, event handlers, unsafe URL material, and
other attributes remain rejected or ignored.

## Security and resource bounds

The sanitizer remains the final boundary. Attribute names and values are not
copied from raw Wikitext; safe tokens are validated, HTML-encoded, and emitted
only in their supported context. Event handlers, inline styles, unsafe URL
material, invalid spans, and oversized values are diagnosed or ignored.

Existing limits remain unchanged: input/output size, parser depth, block and
diagnostic counts, maximum table nesting depth 8, maximum rows 1,000,
maximum total cells 5,000, maximum cell text 100,000 characters, and maximum
attributes per structure 16. Cancellation checks remain active while rendering
rows, cells, and nested content. Shared expansion budgets are unchanged.

## Regression coverage

Focused tests cover canonical tables, headers/data cells, captions, spans,
nested tables, internal links, template-expanded tables, malformed/unclosed
tables, unsafe attributes, template-generated malicious attributes, bounded
rows/cells/nesting, quoted attribute pipes, and nested template separators.

No production database, MediaWiki service, authenticated evidence, Lua
worker, Cargo provider, or host security setting was accessed or modified.

## Known limitations

This evidence is synthetic and bounded. It does not establish exact MediaWiki
1.45 HTML, historical table parity, production migration readiness, Cargo/Lua
parity, or host certification. Complex MediaWiki table continuation rules,
full caption/row/cell attribute semantics, and unsupported extension behavior
remain separate compatibility work.
